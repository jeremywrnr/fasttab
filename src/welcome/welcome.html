fasttab

Press ⌃K (Alt+K on Windows/Linux, or the key you set below) on any page, type a few letters, and hit ↵. An empty query plus ↵ jumps back to your previous tab.

Current shortcut: none ✓ all set

    Some sites keep the shortcut for themselves: ⌃K deletes to the end of the line in Google Docs, and editors like Figma or VS Code for the Web grab keys too. With this on, fasttab listens for its shortcut inside every page and frame, and opens before the site sees the key. Firefox will ask for access to all websites; the listener only watches for this one key combination and sends nothing anywhere.

    Search syntax: g: groups, w: this window, c: recently closed, b: bookmarks, h: history. fzf operators work too: 'exact ^prefix suffix$ !not.
